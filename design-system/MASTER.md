# TomCat — 静态前端设计

基于 ui-ux-pro-max 的 Minimalism / Swiss Modernism 方向；明确优先遵循用户要求：简约、克制，暂不接入上游内核。

- 画布：暖白 #fafbf9；文字：#242a27；辅助文字：#737971；强调：森林绿 #356447。
- 布局：居中 1184px 内容区，清晰网格，24px 卡片间距；移动端单列，保留主要导航。
- 字体：系统无衬线，中文 PingFang SC / Microsoft YaHei；正常正文 14–16px。
- 图标：Lucide React，统一线宽，禁止 emoji 充当控件。
- 圆角：6px 控件、10px 内容卡片；细描边、无渐变、不使用装饰性光效。
- 交互：150ms 颜色过渡、可见键盘焦点、原生模态框、支持 reduced-motion。
- 页面：发现、作品详情、社区、讨论详情、项目管理、场景编辑器、收藏。
- 数据：演示数据与浏览器 localStorage；预览、发布均明确是静态界面，不运行引擎。

## 原创封面

封面由 imagegen 生成，每张一个请求，采用横版画幅、完整场景、无文字/商标/UI。

1. forest：柔和绿色的低多边形林地、红斗篷旅人、小屋和蜿蜒溪流，温暖日光。
2. puzzle：浅蓝背景上的象牙白与珊瑚色等距楼梯和桥梁，微小深色人影、柔和投影。
3. desert：暖色像素沙漠、旅人和橙色越野车、浅杏色天空、远山与落日气氛。
